# Rainham Windows concept website

A standalone, responsive static prototype for reviewing a refreshed Rainham Windows homepage. The design and copy are original; the page is labelled as a concept and is configured not to appear in search results.

## Preview

Open `index.html` in a browser. Project photographs are hosted locally; the font loads from Google Fonts with a system-font fallback.

## GitHub Pages

The test site is published from the root of the `main` branch using GitHub Pages. Push changes to `main` to update the preview.

The preview URL is https://gregzzz54.github.io/rainham-windows-test/.

This is a public preview, not the official business website. `noindex` and `robots.txt` discourage indexing but do not restrict public access.

## Before launch

- Get approval for the design and confirm every business, service, and contact detail.
- Replace the preview notice and `noindex` settings in `index.html` and `robots.txt` only when the production site is ready to be indexed.
- Configure the production canonical URL, social sharing image, sitemap, and analytics after the final domain and page structure are known.
- Check structured business details and local service-area claims against the business's verified information.
- Connect any quote or contact form to a secure, monitored service before offering one.
